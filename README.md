# LexAI — Assistant IA web

Lire AI-GUIDE.md pour les instructions complètes.

Extraire le ZIP et ouvrir dist/index.html dans Chrome ou Edge. Ouvrir Assistant IA, cliquer Charger l’IA et attendre IA prête. WebGPU et un premier téléchargement du modèle sont nécessaires. Aucun Python, abonnement API ou installation de logiciel n’est requis.

Dans le dossier, choisir Analyse rédigée par l’IA. Vérifier la réponse et les références, approuver avec un commentaire, puis exporter. L’approbation reste une simulation de rôle pour ce projet académique.

TXT/MD et texte collé fonctionnent localement. L’import PDF nécessite le site en ligne ou un serveur HTTP. Les poids du modèle sont téléchargés sur demande et ne sont pas inclus dans le ZIP.
